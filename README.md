**🚀 Intern Management System (MERN Stack)**
A full-stack web application built using the MERN stack to manage interns, assign tasks, and track productivity efficiently within an organization.

**📌 Overview**
This system allows mentors to manage interns, assign and review tasks, manage intern's leaves and monitor performance, while interns can track their work, 
submit updates,b take leaves and view progress.

**✨ Features**

🔐 Authentication

-JWT-based login system

-Role-based access (Mentor / Intern)

-Secure password handling

👩‍🏫 Mentor Module

-Dashboard with analytics

-Intern management (Add / Edit / Delete)

-Task assignment & tracking

-Task Review

-Performance monitoring

-Leave management

👨‍💻 Intern Module

-View assigned tasks

-Submit timelogs

-Track progress

-request leaves

🎯System Features

-Productivity tracking

-Analytics dashboard

-Clean UI & structured workflow

**🛠️ Tech Stack**

Frontend: React.js

Backend: Node.js, Express.js

Database: MongoDB

Authentication: JWT

Tools : Git, GitHub, Postman
